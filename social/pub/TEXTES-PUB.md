# 16 pubs AUSSIEWAY — textes à coller dans Meta

Visuels dans ce dossier :
- `A1…A5` : carrousels (un dossier par carrousel, images numérotées dans l'ordre), format 4:5.
- `B06…B12` : images simples, format 4:5.
- `stories/` : 4 vidéos 9:16 pour les emplacements Stories et Reels.

Tous les chiffres viennent du guide (2 303 contacts, onglet Calendrier). Pas de promo, pas de faux avis.

Pour chaque pub, dans le Gestionnaire de publicités Meta :
- **Texte principal** : le texte au-dessus du visuel.
- **Titre** : la ligne en gras sous le visuel.
- **Description** : la petite ligne sous le titre (souvent masquée sur mobile).
- **Appel à l'action** : « En savoir plus ».
- **Lien** : `https://aussieway.fr`

---

## Réglages conseillés pour le test

| Réglage | Valeur |
|---|---|
| Objectif de campagne | **Trafic** (vers le site). Pas « Ventes » : le site n'a pas de pixel Meta. |
| Budget | 5 à 10 € par jour, pendant 7 jours |
| Âge | 18–30 ans |
| Pays | France, Belgique, Suisse, Canada (région Québec) |
| Centres d'intérêt | Working Holiday Visa, Australie, Backpacking, Voyage en sac à dos, PVT |
| Placements | Avantage+ (automatique) : Meta place les 4:5 dans le fil et les 9:16 en Stories et Reels |
| Organisation | 1 campagne, 1 ensemble de publicités, 4 à 6 pubs au départ |

**Ordre de test conseillé :**
1. Semaine 1 : A5 (ce qu'il y a dans le guide), B06, B07, B08, S1, S3.
2. Au jour 7 : coupez les pubs dont le **CPC** (coût par clic) est le plus élevé. Gardez les 2 ou 3 meilleures et remplacez les autres par A1, A2, B09, B10…
3. Regardez aussi les **ventes dans Payhip** jour par jour, pour voir si elles suivent les pics de clics.
