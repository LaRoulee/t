# Liens suivis AUSSIEWAY

Des liens courts qui renvoient vers le site en indiquant d'où vient le visiteur. Les statistiques sont dans GoatCounter : https://aussieway.goatcounter.com (rubriques « Referrers » et « Campaigns »).

| Où le mettre | Lien à utiliser | Ce que GoatCounter affiche |
|---|---|---|
| Bio Instagram | `aussieway.fr/ig` | source : instagram · campagne : bio |
| Bio TikTok | `aussieway.fr/tt` | source : tiktok · campagne : bio |
| Page Facebook (bio + posts) | `aussieway.fr/fb` | source : facebook · campagne : page |
| Pubs Meta (Instagram/Facebook) | `aussieway.fr/pub` | source : meta · campagne : pub |

Les liens vers les guides (aussieway.fr/guide-…) peuvent rester tels quels : Facebook transmet en général sa provenance.

Les clics sur le bouton de paiement sont comptés sous « clic-achat-payhip ». Les ventes elles-mêmes sont dans Payhip.
